# SMTPNG
SMTPNG is a Windows SMTP capture and relay tool built with .NET 10. It provides a GUI and Windows service, durable queued upstream or direct-to-MX delivery with automatic retries, per-recipient status and bounded workers, optional DKIM signing with generated DNS records, a DMARC setup and DNS-check helper, STARTTLS with automatic certificate renewal support, IP/CIDR relay allowlists, optional .eml saving, and daily logs with 30-day retention.
